# Repository Start Checklist

## Before Git initialization

- [ ] Documentation extracted into repository root.
- [ ] Existing first technical specification compared with `docs/PRODUCT_REQUIREMENTS.md`.
- [ ] Duplicate file names resolved deliberately.
- [ ] No secrets.
- [ ] No real personal or company data.
- [ ] No temporary archives inside the repository.

## Git initialization

- [ ] `git init`.
- [ ] Default branch is `main`.
- [ ] `.gitignore` exists before framework or environment files appear.
- [ ] `git status` contains only intended documentation.
- [ ] First commit message is coherent.

Suggested first commit:

```text
docs: initialize ETRN Flow project brain
```

## GitHub

- [ ] Repository created as private.
- [ ] Remote URL verified.
- [ ] Push targets `main`.
- [ ] Repository URL recorded in `PROJECT_BLUEPRINT.md`.
- [ ] `docs/HANDOFF.md` updated after push.

## After push

- [ ] Remote file tree matches local accepted tree.
- [ ] No secret or personal data found in GitHub.
- [ ] Working tree is clean.
- [ ] Architecture Plan is the next task.
