# Agent Routing

## Codex

Use for:

- architecture planning;
- repository foundation;
- backend and domain workflow;
- multi-file features;
- database schema and migrations;
- security hardening;
- CI and deployment configuration;
- difficult debugging.

Complex tasks begin in Plan mode.

## Copilot / SourceCraft

Use for:

- small UI components after design is accepted;
- local copy or style adjustments;
- simple tests following existing patterns;
- concise documentation updates;
- Makefile based on existing scripts.

## Lovable

Use for:

- visual concept exploration;
- page and component composition;
- design system alternatives;
- responsive layout prototypes.

Lovable does not decide domain architecture, security or data contracts.

## GPT

GPT writes prompts, reviews output and accepts or returns work. Agents do not set project strategy independently.
