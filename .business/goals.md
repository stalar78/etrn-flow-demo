# Goals

## Main goal

Turn a timely regulatory and operational change into a credible productized StalarVision service.

## Product success metric

A visitor completes the main demo path without instruction and reaches the implementation CTA.

## Commercial success metric

At least one qualified lead for audit, integration or custom development after launch of targeted traffic.

## Stage goals

| Stage | Goal | Exit metric |
|---|---|---|
| Idea | Accept product scope | MVP and exclusions approved |
| Architecture | Choose sustainable foundation | Blueprint, security and deployment accepted |
| Foundation | Create tested project skeleton | Local and CI checks pass |
| MVP Build | Complete main interactive workflow | End-to-end demo path works |
| Release | Deploy public demo | Production QA passed |
| Growth | Validate demand | Qualified leads and analytics data |
