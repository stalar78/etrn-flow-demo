## Accepted direction

- Start with a public interactive demo.
- Do not implement real EPD operator integration in MVP.
- Use synthetic data only.
- Create a separate commercial page on StalarVision and a separate demo subdomain.
- Build a minimal but credible version, deploy it, then continue improving.
- Maintain an adapter boundary for future operator integration.

## Primary audience

Small and medium carriers, shippers, forwarders and companies with logistics/warehouse processes.

## Main MVP proof

A visitor can create and advance a synthetic shipment through multiple roles, see an event history, inspect a problem and understand what StalarVision offers.

## Active risks

- accidental positioning as an accredited operator;
- excessive scope and TMS overbuilding;
- static-looking demo without credible state changes;
- public abuse of guest sessions;
- legal wording presented without verification.
